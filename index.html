🤖 AI Safety, Agent Verification & Security
01 Claude Code PreToolUse Hook & System Gate
Intercept high-risk tool executions from CLI agents (e.g., Claude Code, AutoGPT). A pre-tool hook script routes proposed commands (like rm -rf or git push --force) over USB CDC serial. The host process remains blocked until you physically press BtnA (Approve) or BtnB (Reject) on the M5Stick.

02 Local LLM Hallucination & Confidence Gauge
Connects over Wi-Fi to local LLM servers (Ollama, LM Studio). Streams per-token log probabilities (logprobs), calculating a rolling average confidence score in real time. Renders a live needle/gauge on the TFT display, flashing red and chirping when model output uncertainty spikes.

03 Agent System Prompt & Memory Drift Monitor
Passes LLM memory updates and context buffers to the device over serial/Wi-Fi. Using the ESP32-S3's hardware SIMD vector instructions (esp-nn), it computes rolling hashes and vector similarity checks against a trusted master persona in flash, instantly flagging silent prompt injection or system context corruption.

04 Hardware Prompt Injection Serial Filter
Acts as an inline hardware proxy filter between scraping tools and your AI agent's inputs. Performs ultra-fast string and pattern matching on raw text payloads hardware-side to strip known jailbreak signatures before payload strings reach the model context.

05 Offline Edge Vector DB Network Fingerprinter
Captures 802.11 Wi-Fi management frame attributes (IE table ordering, supported rates, vendor OUI flags). Uses esp-nn vector dot-product calculation on-chip to evaluate network devices against a trusted vector baseline, flagging spoofed access points or MAC addresses locally.

📦 SECTION 2: Established Open-Source Community Projects (10 Options)
Active, verified open-source security tools and firmware built specifically for the ESP32 / ESP32-S3 and M5Stack platform.
01 Bruce Firmware
A popular multi-tool offensive security firmware for M5Stack hardware (Cardputer, StickC Plus, Core2) featuring Sub-GHz, IR transmitter replay, Wi-Fi scanning, and BLE spamming capabilities in a portable UI.
🔗 Verified Repo: github.com/pr3y/Bruce
02 GhostBLE (M5Stack Privacy Scanner)
Bluetooth Low Energy (BLE) privacy and tracker detection tool for M5Stack devices. Filters company IDs (Apple FindMy 0x004C, Tile, SmartTag) and tracks persistent MAC RSSI signatures to alert users when an AirTag or rogue tracker is following them.
🔗 Verified Repo: github.com/SmonSE/GhostBLE
03 PathShield Anti-Tracking Tool
An RF awareness tool built for M5StickC Plus hardware. Uses persistent multi-window scoring across dual BLE and Wi-Fi scans to detect unwanted tracking devices like AirTags, Tile, and SmartTags.
🔗 Verified Repo: github.com/lukeswitz/PathShield
04 ESP32 Marauder
A suite of Wi-Fi and Bluetooth offensive/defensive analysis tools designed for ESP32 hardware. Performs packet sniffing, beacon spamming, PMKID capture, and raw 802.11 packet analysis for security auditing.
🔗 Verified Repo: github.com/justcallmekoko/ESP32Marauder
05 ESP32-SwiftPair-BLE-Spammer
Utilizes the ESP32 Bluetooth Low Energy stack to send rapid, continuous SwiftPair and FastPair advertisement packets, testing host OS notification resiliency and BLE stack stability.
🔗 Verified Repo: github.com/wirebits/ESP32-SwiftPair-BLE-Spammer
06 ESP32 BLE Beacon Spam
Generates randomized iBeacon and BLE advertisement frames with rotating OUI vendor data and MAC addresses to audit local BLE scanning tools and beacon collectors.
🔗 Verified Repo: github.com/tobozo/ESP32-BLEBeaconSpam
07 Pwnagotchi Framework
An open-source AI-powered Wi-Fi auditing tool that listens to WPA handshakes. Lightweight ESP32/M5Stick ports communicate with PwnGrid over BLE advertisements to exchange stats and status faces with nearby devices.
🔗 Verified Repo: github.com/evilsocket/pwnagotchi
08 ESP32 Captive Portal
Sets up an isolated SoftAP with an embedded DNS responder redirecting web requests to a local SPIFFS-hosted HTML page to evaluate user security awareness against unencrypted public Wi-Fi access points.
🔗 Verified Repo: github.com/cdolina/esp32-captive-portal
09 ESP32-BlueJammer (2.4GHz Audit)
A hardware project utilizing ESP32 microcontrollers and radio modules for controlled 2.4GHz spectrum testing, channel hopping, and signal disruption research.
🔗 Verified Repo: github.com/EmenstaNougat/ESP32-BlueJammer
